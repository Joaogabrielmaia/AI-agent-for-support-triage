# Importar clientes de uma planilha

## Formato do arquivo
Em Clientes > Importar, envie um arquivo CSV ou XLSX com as colunas nome, telefone, e-mail e data de nascimento. Apenas nome e telefone são obrigatórios. Cada arquivo pode ter até 5.000 clientes.

## Duplicidades
O telefone é a chave para identificar duplicados. Se o telefone já existe no sistema, a linha atualiza o cadastro existente em vez de criar outro.

## Revisão antes de confirmar
Antes de concluir, o sistema mostra uma prévia com linhas válidas e linhas com erro. Você pode baixar o relatório de erros, corrigir a planilha e enviar de novo.
